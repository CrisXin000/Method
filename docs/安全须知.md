# 安全须知

出光、换滤光、做异常代理之前先读完本页。本页是实验门禁，不是激光安全培训的替代，也不能代替设备制造商的风险评估。

## 出光门禁

同时满足以下四条，才允许出光：

1. 激光波长防护片（光纤激光常见为 1000 nm 短通或 1064 nm 陷波；**实际波长以机床标牌为准，待核实时不得沿用本句示例**）已装入光路，并有第二人目视确认。
2. 滤光座固定，片不松动、无可见裂纹、膜面朝向符合片商说明。
3. 与激光波长匹配的护目镜已佩戴；旁人进入加工区同样佩戴。
4. 停光方式当场可用：激光使能/急停可立即切断，灭火器材在手边，有人值守。

未装好防护片时，允许做的只有：盖镜头暗场、机床停机时的车间背景、**不出光**的机械空跑。文件名里出现 `正常切割` 或 `异常代理` 时，滤光字段必须包含 `SP1000` 或 `NF1064`（或记录表里写明的等效防护片型号）。

## 激光回返

加工区的回返光、镜面反射和金属漫反射会打坏 CMOS，也会伤眼。

- 低成本默认**旁轴**斜看，避开切割头主光路。旁轴仍可能被高反材料的漫反射过曝，不能当成已经安全。
- 同轴能看见回火，也承受全部回返能量。没有二向色镜先把激光波长反射到吸收阱之前，不要把相机放进同轴光路。
- 目录上的介质膜滤光片多用于光谱，**不是**激光防护件。把它单独当作相机或眼睛的防护，依据不足。
- 熔池核心允许饱和，饱和面积可以当作特征；禁止靠抬增益去「看清」熔池。

## 滤光片：OD 与 LIDT

- **OD（光密度）**描述设计波长上的透过率：OD 4 表示该波长透过率约为 10⁻⁴，OD 6 约为 10⁻⁶。OD 必须对应**实际激光波长**和**实际入射角**。带通片的中心波长会随入射角移动。
- **LIDT（激光损伤阈值）**描述膜层能承受的功率密度或能量密度（连续光多为 W/cm²，脉冲多为 J/cm²）。只写 OD、不写 LIDT 的片子，不能判断会不会被打坏。
- 本库**不给出**万能 OD 或 LIDT 数字。按该机功率、光斑落在片子上的面积、脉宽/连续方式核算；片商曲线对不上就标「待核实」，继续不出光。
- 低端组合是：国产 750 nm 带通，串联 1000 nm 短通或 1064 nm 陷波，用来提高熔池对比并压回返。串联之后仍要单独核算激光波长上的 OD 与 LIDT。进口对照片（如 Thorlabs 1064 nm 陷波）只说明「高 OD 片存在」，不表示手边国产片达到同一指标。
- 保护窗（如 JGS1 石英可换片）挡飞溅，不替代陷波/短通。滤光片放在吹扫腔内侧，避免烟尘镀在膜上。

## 护目镜

- 镜片标注必须覆盖**这台激光的波长**。光纤激光常见 1064 nm，CO₂ 激光为 10.6 μm，两种护目镜不能混用。波长以机床标牌为准。
- 看标注上的波长区间和 OD。墨镜、建筑眼镜、相机滤光片都不能当护目镜。
- 需要的 OD 来自该设备的风险评估，本库不指定一个「足够」的数字。
- UV 火焰管只负责毫秒级硬触发，不保护眼睛，也不能代替视觉定位。

## 异常代理

方案 1 的异常代理只做光学标定：降速或重复烧路径至发红、冒烟，或在安全距离使用受控阴燃木条/线香。禁止失控明火蔓延。全程值守，灭火准备就绪，可立即停光。无人时不做异常段。

## 监测不是安全功能认证

ISO 11553-1:2020 的范围是激光辐射危害，火灾爆炸等材料作用次生危害不在其覆盖之内（以 [ISO 正式页面](https://www.iso.org/standard/67658.html) 文本为准）。装了火焰监测，不等于「符合 ISO 11553」。GB/T 18490.1 将烟尘/颗粒等引起的火灾爆炸列入危险，要求风险评估与控制（以 [国家标准文本](https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=7778B6341BBE5F5CD41AD429EE9F70F4) 为准）。

本方案定位是辅助监测和减损。若「停光」要当作安全功能，需按 ISO 13849-1 / IEC 62061 做整机 PL/SIL 评估，不能只靠应用层模型。底线仍是联锁、围护和抑爆。
