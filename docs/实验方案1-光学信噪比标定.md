# 实验方案 1：光学信噪比标定

用可控实验，在 mono 相机与滤光组合下，找出异常燃烧相对背景信噪比最高、且正常切割伪阳可控的滤光 × 曝光 × 增益。结果只锁定光学与曝光增益，不代替方案 2 的数据采集和模型验收。

出光前读 [安全须知](安全须知.md)。**滤光未就绪，不出光。**

指标与选参约定来自选型 canvas 的实验方案 1，本文件写成可执行步骤。性能与价格数字不在本方案测量范围内。

## 1. 目标与指标

在录制码值上计算（与日后部署链路同一像素格式）。全矩阵使用同一 gamma / 位深，禁止混用 raw 与压缩视频的码值。

信号区均值记为 μ_s，背景区均值与标准差记为 μ_bg、σ_bg。

**信噪比**

```text
SNR = (μ_s − μ_bg) / σ_bg
```

**对比度**

```text
C = (μ_s − μ_bg) / μ_bg
```

补充约定：

- σ_bg = 0，或背景大面积卡在 0 / 满量程，该帧 SNR 无效，不参与中位数。
- μ_bg 低于暗场读出噪声地板时，C 会失真，只作参考。选参以 SNR 和伪阳率为准。暗场片段不计算 C。
- μ_s、μ_bg 都在事先写死的 ROI 内计算，禁止看完视频再挑最亮区域。

**正常工况伪阳率**

同一判定阈值下，正常切割片段里被判为「火」的帧占比：

```text
阳性：μ_s > μ_bg + k · σ_bg
伪阳率 = 阳性帧数 / 正常切割有效帧数
```

k 对全部候选组共用。取法见第 6 节。有效帧去掉作废帧（见过曝）。

**选参标准**

在伪阳率 < 1% 的约束下，选取异常代理片段 **SNR 中位数最高** 的滤光 × 曝光 × 增益。对比度用于并列时的次排序：SNR 中位数差距在 10% 以内时，取 C 的中位数更高者。

## 3. 实验矩阵

因子要覆盖完整，但**无防护片的水平禁止与出光工况组合**。

| 因子 | 水平 | 说明 |
| --- | --- | --- |
| 滤光 | `NONE`；`ND0.3`；`ND1.0`；`BP550`；`BP590`；`BP650`；`BP750` | 窄带带宽 20–40 nm。名字用片上标称中心波长 |
| 激光防护 | 无 / `SP1000` / `NF1064` | 出光组必须带 `SP1000` 或 `NF1064`（或记录表中的等效型号），并且窄带/ND 与防护片串联 |
| 曝光 | 0.1 / 0.5 / 1 / 5 / 20 ms | 文件名写作 `0.1ms`、`0.5ms`、`1ms`、`5ms`、`20ms` |
| 增益 | 0 dB / +6 dB | 文件名写作 `0dB`、`6dB`。禁止自动增益 |
| 工况 | 暗场 / 车间背景 / 空跑 / 正常切割 / 异常代理 | 见第 4 节 |
| 材料 | 主材料 + 复测材料；无材料写 `无` | 用中文简称，如 `亚克力`、`木板`、`铝` |

每组录 **30–60 秒**。暗场、车间背景固定 30 秒。

### 3.1 允许的组合

| 工况 | 允许的滤光字段 | 禁止 |
| --- | --- | --- |
| 暗场、车间背景、不出光空跑 | 任意，含 `NONE` | 无 |
| 低功率空跑、正常切割、异常代理 | 必须含 `SP1000` 或 `NF1064` | `NONE` 以及任何未串联防护片的窄带/ND |

窄带与防护片串联时，滤光字段写成 `BP750+SP1000` 这种形式。

### 3.2 建议分两段做完，避免无效全交叉

全交叉（全部滤光 × 5 档曝光 × 2 档增益 × 3 个出光工况）组数很大。按下面两段执行，每一因子都会出现；获胜点再用邻域确认。

**筛查（主材料，增益先锁 0 dB）**

- 滤光：`ND1.0+SP1000`、`BP650+SP1000`、`BP750+SP1000`。若片组里还有 550/590 与陷波片，各加一组 `BP550+SP1000`、`BP590+SP1000`、`BP750+NF1064`。
- 曝光：0.5 / 1 / 5 ms。
- 工况：不出光空跑、正常切割、异常代理。每种滤光组合先各录一条暗场和一条车间背景（曝光可用 20 ms，增益 0 dB）。

**定参（只围绕筛查领先的 1–2 个滤光）**

- 曝光补齐 0.1 ms 与 20 ms。
- 增益补上 +6 dB。
- 若筛查里 ND0.3 尚未出现且领先组过曝，追加 `ND0.3+SP1000` 或在领先窄带上再叠 ND。

**跨材料**

只用获胜的那一个滤光 × 曝光 × 增益，在其余材料上各录正常切割与异常代理。不再把矩阵重跑一遍。

## 4. 操作顺序

每种滤光组合按此顺序，不要跳步。换片子之后从暗场或车间背景重新开始。

1. **暗场基线**  
   镜头盖盖严，环境光漏不进。录 30 秒。用来看读出噪声和坏点。此步不出光。

2. **车间背景**  
   机床停止、车间灯保持日常状态。录 30 秒，得到 μ_bg、σ_bg 的灯光合底。此步不出光。

3. **空跑**  
   优先：轴运动、**不出光**。若必须看低功率空跑，防护片已装好才允许，并在记录表注明功率。用来排除振动、频闪和卷帘条纹。

4. **正常切割**  
   该材料的常用功率、速度、气压。录满 30–60 秒。伪阳率只用这段计算。穿孔开始前的帧单独注明，不并进伪阳分母（穿孔光斑形态不同）。

5. **异常代理**  
   二选一，并在记录表写明是哪一种：  
   - 工艺内：降速或沿同一路径重复烧，直到发红、冒烟。火势变大立即停光。  
   - 工艺外：安全距离处的阴燃木条或线香，只给光学一个「持续热源」对照。  
   这段不能代替真实事故验收。

6. **换滤光**  
   停光、卸片、装新片、目视确认，再从步骤 1 或 2 重跑。

**过曝作废（单组）**

画面中心 50% × 50% 区域内，满量程像素占比 > 5% 时，该帧记为过曝帧。若该组**中位帧**已满足这一条，整组作废：缩短曝光或加 ND 后重录，禁止提高增益。

## 5. 文件命名与 ROI

### 5.1 文件名

```text
滤光_曝光_增益_材料_工况.mp4
```

示例：

```text
NONE_20ms_0dB_无_暗场.mp4
NONE_20ms_0dB_无_车间背景.mp4
BP750+SP1000_1ms_0dB_亚克力_空跑.mp4
BP750+SP1000_1ms_0dB_亚克力_正常切割.mp4
BP750+SP1000_1ms_6dB_木板_异常代理.mp4
```

规则：

- 五段用下划线连接，滤光内部的串联用加号，不要再加下划线。
- 曝光、增益只用第 3 节列出的写法。
- 工况只用：`暗场`、`车间背景`、`空跑`、`正常切割`、`异常代理`。
- 同一组重录时，在扩展名前加 `_r2`、`_r3`，不要覆盖原文件。
- 视频与一份同名 `.csv` 记录表放在同一目录（记录表字段见第 7 节）。数据不要提交进本仓库。

### 5.2 ROI（全片一致）

- **信号 ROI**：正常切割取切缝邻域的固定窗口。异常代理使用开录前写死的窗口（例如相对夹具基准的固定矩形），禁止逐帧手动画框，禁止事后改到最亮处。
- **背景 ROI**：与信号 ROI 等面积，避开切缝、夹具高光和画面边缘 10%。
- 同一安装位姿下，坐标全程不变。换材料后切缝位置变了，允许按机械基准重标**一次**，把新旧坐标写进记录表。
- 分析时把 ROI 画在首帧导出的对照图上，随记录表保存，便于复核。

## 6. 离线分析与热力图

本仓库不提供分析脚本。按下述约定用任何表格工具计算，阈值对所有候选组相同。

### 6.1 逐帧表

每个视频导出一张 CSV，列至少包括：

| 列 | 含义 |
| --- | --- |
| `file` | 文件名 |
| `frame` | 帧序号，从 0 起 |
| `filter` `exposure_ms` `gain_db` `material` `condition` | 与文件名一致 |
| `mu_s` `mu_bg` `sigma_bg` | ROI 均值与背景标准差 |
| `snr` `contrast` | 按第 1 节公式；无效则空着 |
| `sat_frac_center` | 中心 50%×50% 满量程像素占比 |
| `valid` | 过曝帧或 σ_bg 无效时为 0 |

码值使用录制值。彩色模组只统计开工时选定的那个通道。

### 6.2 组汇总

每一组（同一文件名，不含 `_r2` 重录；重录以记录表指定的采用版本为准）计算：

- 异常代理：`snr` 的中位数、`contrast` 的中位数（只统计 `valid=1`）
- 正常切割：按共用 k 算出的伪阳率
- 过曝帧占比 = `sat_frac_center > 0.05` 的帧数 / 该组总帧数

### 6.3 k 的取法

1. 只在筛查 + 定参阶段、未作废的组上选 k。
2. k 从一组公共候选里取（建议 3、4、5、6、8）。
3. 选取**最小**的 k，使得每一个仍保留的光学组合，其正常切割伪阳率都 < 1%。
4. 若某个组合在最大候选 k 下仍 ≥ 1%，淘汰该组合。不要为了保住它再把 k 加大——阈值抬高会同时压掉真异常。
5. 把最终 k 写进汇总表。以后跨材料复测沿用这个 k。

### 6.4 热力图约定

- 增益 0 dB 与 +6 dB **分面**，各一张，不要画在同一颜色轴里。
- **行** = 滤光字段（如 `BP750+SP1000`）。
- **列** = 曝光（0.1、0.5、1、5、20 ms）。
- **颜色** = 该格异常代理 SNR 中位数。作废或缺测的格子留空，不要插成 0。
- **格内文字** = 正常切割伪阳率，写成百分数，保留一位小数（例：`0.4%`）。
- 颜色轴固定为 SNR 0–10，超过 10 的格子颜色与 10 相同，格内另注实际中位数。这样不同批次的图能并排比较。
- 图题写明：材料、k、码值格式（mono 或哪一通道）、日期。

### 6.5 选定工作点

在伪阳率 < 1%、且该组未作废的格子中，取异常 SNR 中位数最高者。SNR 中位数相对差距 ≤ 10% 时，取对比度中位数更高者；仍相同则取曝光更短的一格（拖影更小）。

记录三行结论：获胜滤光、曝光、增益；k；该格的 SNR 中位数、伪阳率、过曝帧占比。

## 7. 记录表字段

每组一行，与视频一起存放，不提交到本仓库：

`日期, 操作者, 滤光片型号与标称, 防护片型号, 曝光, 增益, 材料, 功率, 速度, 气压, 工况, 代理类型, 信号ROI, 背景ROI, 通道, 文件名, 是否作废, 备注`

## 8. 验收标准

验收对象是**选定的那一个工作点**，不是矩阵里每一格。跨材料用第 3.2 节的复测。

| 指标 | 门槛 | 更好 |
| --- | --- | --- |
| 异常代理 SNR 中位数 | ≥ 5 | ≥ 8 |
| 正常切割伪阳率（共用 k） | < 1% | 越低越好 |
| 过曝帧占比 | < 2% | — |
| 换材料复测 | 每种材料的异常 SNR 中位数相对主材料掉点 ≤ 30% | — |

掉点定义：`(SNR_主 − SNR_该材料) / SNR_主`。只对异常代理、同一工作点、同一 k 计算。某种材料掉点超过 30%，该工作点不能宣称「跨材料通过」；可以保留为单材料参数，并在记录表标明适用材料。

未达标时的调整顺序：先换窄带中心波长或加 ND，再缩短曝光。仍然不够，再考虑全局快门模组或更高 OD 的短通/陷波（OD 与 LIDT 仍按安全须知核算，不在本方案里假定一个数）。不要靠提高增益通过验收。

通过方案 1 之后，若 UV 加面积/时间阈值已经把伪阳压住，停在规则，进入方案 2 的「不上深度学习」分支。只有规则不够时，才按方案 2 采集和标注。
