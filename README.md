# Method

激光加工区的火焰异常监测方法与实验文档库：面向 ESP32-P4 低成本端侧方案，先标定光学信噪比，再决定是否采集数据并上深度学习。

本仓库**只放文档**。不含固件、训练代码、模型权重或大数据文件。Owner：[CrisXin000](https://github.com/CrisXin000)。

许可证待定（仓库暂不放置 `LICENSE`）。

完整选型论证、对照表与外部来源见：[激光加工火焰异常监测 · ESP32-P4 低成本端侧选型](https://cursor.com/canvas/store-693791af-e96f-4b77-b641-495ebe99e556/f8095b87-b939-4f65-9152-1f0b257f93fb)。

## 安全提示

**滤光未就绪，不出光。** 1064 nm（或机型实际波长）防护片未安装、未目视确认之前，禁止出光，包括低功率空跑。护目镜保护眼睛，滤光片保护相机，二者不能互相替代。出光前先读 [docs/安全须知.md](docs/安全须知.md)。

## 阅读与执行顺序

1. [安全须知](docs/安全须知.md)：任何出光、任何异常代理之前。
2. [实验方案 1：光学信噪比标定](docs/实验方案1-光学信噪比标定.md)：**必做**。用它锁定滤光、曝光、增益。
3. [实验方案 2：是否上深度学习，以及数据采集与标注](docs/实验方案2-是否上深度学习与数据采集标注.md)：**可选**。方案 1 未达标，或 UV 加阈值已经够用时，不要进入本步。
4. [选型结论摘要](docs/选型结论摘要.md)：说明为什么是 ESP32-P4 + MIPI + ESPDet-Pico + UV 硬触发。可随时作背景阅读，不替代方案 1。

方案 1 的验收（异常 SNR 中位数 ≥ 5、正常工况伪阳率 < 1%、过曝帧 < 2%、跨材料 SNR 掉点 ≤ 30%）通过之后，才讨论方案 2。
